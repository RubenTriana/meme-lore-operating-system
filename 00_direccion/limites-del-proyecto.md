# Límites del proyecto

- El sistema no escribe la novela por el autor.
- No se promueven hipótesis a canon ni se resuelven vacíos por conveniencia.
- No se mezcla composición con microedición durante el primer borrador.
- No se imitan voces reconocibles de autores vivos.
- No se realizan más de tres ciclos editoriales profundos por capítulo sin solicitud expresa.
- Métricas automáticas detectan zonas de lectura; no puntúan calidad literaria.
