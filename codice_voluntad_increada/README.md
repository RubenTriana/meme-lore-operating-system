# El Códice de la Voluntad Increada

Módulo de desarrollo para un paratexto de voces múltiples dentro del universo de la tetralogía.

## Estado de autoridad

- `data/universe_master.json` es el canon técnico activo.
- Este módulo contiene hipótesis, borradores y registros editoriales; no modifica el canon.
- El Códice no establece la cronología de los hechos ni entrega una respuesta metafísica definitiva.

## Lectura prevista

El lector encuentra fragmentos breves antes o después de partes selectas de las novelas. Las alusiones diegéticas son secundarias: ningún personaje debe reconstruir el Códice como misión principal.

## Primer bloque

[*El Silencio Anterior*](books/01_silencio_anterior/brief.md) inaugura la voz del Códice como una meditación disputada sobre la posibilidad aún no confiscada.
