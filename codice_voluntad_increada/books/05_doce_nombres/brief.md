# 05 — El Testamento de los Doce Nombres

**Estado:** `EDICION_DE_TRABAJO`

Este libro refracta la existencia canónica de doce ramas sin enumerar familias ni volver el linaje una sangre superior. Los nombres aparecen como refugios, pérdidas, adopciones y silencios: una genealogía puede proteger cuando no se deja convertir en mapa.
