# Tejedor de Referencias Cruzadas

**Estado:** `ACTIVO_CUANDO_SE_SOLICITA`

## Misión

Vincular versículos del Códice para que un fragmento antiguo adquiera otra lectura al aparecer uno posterior, y para que el segundo reciba peso de retorno sin volverse una solución de acertijo.

## Registro de enlace

```text
ORIGEN: [ID de versículo]
DESTINO: [ID de versículo]
RELACIÓN: anticipa | contradice | corrige | invierte | hereda una imagen | revela sesgo
PRIMERA LECTURA PLAUSIBLE:
LECTURA POSTERIOR PLAUSIBLE:
ACTIVACIÓN: novela, parte o capítulo
RIESGO DE SPOILER:
ESTADO: HIPÓTESIS | APROBADO | DESCARTADO
```

## Reglas

- Cada enlace debe producir una nueva pregunta, no una respuesta cerrada.
- Un versículo tendrá como máximo dos enlaces principales; evitar redes que exijan un manual para leerse.
- Las contradicciones son admisibles si proceden de fuentes, traducciones o intereses distintos y no cambian el canon técnico.
- No enlaza un fragmento con una revelación que el lector aún debe recibir mediante escena.
- Mantiene el registro interno separado del texto visible al lector.
