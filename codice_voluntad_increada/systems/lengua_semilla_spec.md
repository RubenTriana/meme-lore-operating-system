# Especificación de la Lengua Semilla

**Estado:** `CANDIDATO_ARTISTICO_NO_CANONICO`
**Función aprobada:** ninguna afirmación de esta especificación modifica el canon técnico. La escritura solo opera como anomalía textual mínima y nunca como origen factual de MEME, SOMA o DAFX.

## Naturaleza

La Lengua Semilla es un sistema tecnosagrado inventado de señales, relaciones y operaciones. No es alfabeto, cifrado de sustitución, lenguaje de programación ni copia de una escritura histórica. Sus signos se dibujan con curvas, nudos, vacíos y cortes propios; la interfaz los genera como SVG estable, no mediante glifos Unicode prestados.

## Siete operadores

Los operadores no se pronuncian; modifican distancia, orientación o contacto entre primitivas.

| Operador | Forma | Función probable |
|---|---|---|
| O1 · vínculo | trazo bajo dos signos | conserva relación |
| O2 · inversión | signo girado | niega una lectura sin borrarla |
| O3 · suspensión | punto exterior | deja el resultado abierto |
| O4 · repetición | dos muescas | exige volver a ejecutar el rito |
| O5 · testimonio | círculo parcial | marca lo visto, no lo explicado |
| O6 · bifurcación | separación en Y | mantiene dos salidas |
| O7 · sello | corte transversal | prohíbe completar la secuencia |

## Sintaxis

1. Cada inscripción contiene entre una y nueve líneas.
2. Una línea admite de dos a seis primitivas y cero o un operador dominante.
3. La orientación importa: izquierda a derecha indica transmisión; centro hacia afuera, reparto; retorno al centro, restitución dudosa.
4. Una secuencia sellada no puede recibir glosa dentro del artefacto.
5. La repetición nunca produce identidad perfecta: el último signo debe variar o quedar ausente.
6. Dos bloques extensos no pueden aparecer consecutivamente.
7. La presencia visible debe permanecer entre 2 % y 5 % del cuerpo del códice.

## Apariciones candidatas

- `CVI-F01`: cuatro líneas sobre posibilidad y borde.
- `CVI-F05`: tres líneas alrededor de la corona incompleta.
- `CVI-F07`: cinco líneas separadas por un vacío central.
- `CVI-F09`: dos líneas, la segunda interrumpida por el daño de fuego.

La gramática completa permanece interna. Las traducciones visibles se presentan como conjeturas de copistas posteriores, nunca como equivalencias definitivas.
