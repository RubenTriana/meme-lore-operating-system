# Plan mínimo activo

ESTADO: SIN INTERVENCIÓN ACTIVA

La intervención hipotética de prueba no abre un plan real. Activar este archivo únicamente cuando exista evidencia textual, el tutor confirme una necesidad pedagógica y el autor acepte trabajarla.

Cuando se active, registrar una sola habilidad dominante, duración total, lectura mínima, práctica, aplicación, criterio de éxito y fecha de reevaluación.
