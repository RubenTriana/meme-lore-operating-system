# Prácticas deliberadas

Guardar una ficha por intervención. Cada práctica debe trabajar una habilidad, usar evidencia concreta, respetar la dosis mínima y terminar con una sola acción.

Las pruebas de arquitectura deben identificarse como hipotéticas y no cuentan en el perfil ni en el registro de transferencia.
