# Aprendizaje deliberado

Este directorio convierte patrones reales del manuscrito en intervenciones educativas breves y comprueba si lo aprendido reaparece en la novela. No es una biblioteca general ni una lista de deberes.

## Flujo

1. Un especialista aporta evidencia de un problema.
2. El tutor decide si el problema es pedagógico y si merece interrumpir el flujo creativo.
3. El Mentor de Aprendizaje aísla una habilidad, evalúa fuentes y diseña una práctica mínima.
4. El autor realiza la práctica y la aplica al manuscrito.
5. El tutor evalúa el resultado y el sistema registra la transferencia.

El agente se activa con solicitudes como «Activa el Mentor de Aprendizaje», «Dame la lectura mínima para entender este problema», «Prepara una sesión de veinte minutos» o «¿Qué habilidad me está frenando más?». También puede concluir que conviene seguir escribiendo sin estudiar nada.
