# Protocolo de canon

1. Consultar primero `data/universe_master.json`; usar respaldos y patches solo como historia o propuestas.
2. Identificar fuente, versión, estado y fecha de cada afirmación.
3. Clasificar: canónico, interpretación, sospecha, secreto, hipótesis, alternativa o descarte.
4. Revisar cronología, ubicación, estado físico/emocional, conocimiento por personaje, conocimiento del lector, promesas, semillas y reglas del mundo.
5. Ante conflicto, detener promoción, registrar ambas fuentes y pedir decisión autoral.
6. Aplicar cambios al canon solo mediante propuesta, validación, comparación y aprobación explícita.

Las métricas, índices derivados, simulaciones, pruebas y documentos editoriales no son canon.
