# Modo Revisión de Capítulo

Activar únicamente cuando el autor lo solicite expresamente o confirme que terminó un capítulo.

## Recursos

- Recomendar GPT-5.6 Terra con razonamiento Medium.
- Usar como máximo dos agentes especializados y solo si aportan competencias distintas.
- Leer el capítulo, `CONTEXTO_ACTIVO.md` y únicamente el canon directamente relevante.

## Flujo

1. Diagnosticar antes de proponer cambios.
2. Identificar un problema dominante y hacer una sola pasada principal.
3. No convocar todos los agentes ni permitir análisis redundantes.
4. No generar cuatro candidatos salvo petición expresa.
5. Permitir primero que el autor revise; no reescribir el capítulo completo automáticamente.
6. Actualizar continuidad y memoria solo después de que el autor apruebe las decisiones.

Si durante la revisión aparece una contradicción grave, una comparación extensa o una necesidad de torneo, explicar el cambio de alcance y pedir activación explícita del Modo Profundo.
