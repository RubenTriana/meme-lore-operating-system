# Modo Profundo

Activar solo mediante orden expresa para torneo editorial, cierre definitivo de capítulo, contradicción canónica grave, revisión macro, arquitectura de novela o comparación profunda de versiones.

## Anuncio previo obligatorio

Antes de actuar, informar:

- qué agentes se activarán;
- qué archivos se leerán;
- por qué el modo profundo es necesario;
- qué resultado se producirá.

Esperar autorización si el alcance anunciado excede la orden recibida.

## Recursos y límites

- Recomendar GPT-5.6 Sol con razonamiento High.
- No usar Ultra salvo petición expresa.
- Activar únicamente subagentes con aportes no redundantes.
- No permitir que varios agentes analicen lo mismo sin una razón comparativa explícita.
- Mantener originales, candidatos y descartes separados.
- Diagnosticar antes de generar alternativas; el integrador editorial es el único especialista que puede crear una integración.
- Registrar cambios canónicos o de continuidad solo después de aprobación del autor.

El modo termina al entregar el resultado anunciado; no permanece activo para consultas posteriores salvo nueva orden.
