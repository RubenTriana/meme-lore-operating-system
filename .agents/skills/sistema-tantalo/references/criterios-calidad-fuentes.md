# Criterios de calidad de fuentes

## Jerarquía

1. **Académicas o institucionales abiertas:** universidades, centros universitarios de escritura, cursos abiertos, publicaciones académicas e instituciones educativas.
2. **Profesionales especializadas:** editoriales, escuelas reconocidas, revistas literarias, editores y escritores con experiencia verificable.
3. **Libros:** recomendar capítulo, sección o rango aproximado; explicar qué buscar y estimar el tiempo. Priorizar editoriales, bibliotecas, préstamo autorizado, vista previa legal, dominio público o licencias abiertas.
4. **Blogs, videos y comunidades:** usar solo con autoría verificable, contenido específico y contraste suficiente.

Nunca buscar, descargar, almacenar ni recomendar copias no autorizadas. Un PDF encontrado en un buscador no se presume legal.

## Evaluación

Puntuar de 0 a 5:

- autoridad;
- pertinencia;
- claridad;
- aplicabilidad;
- concisión;
- calidad de ejemplos;
- acceso legal;
- adecuación al nivel;
- transferencia a *Operación Tántalo*.

Calcular como apoyo:

`valor_por_minuto = (pertinencia + aplicabilidad + transferencia + claridad) ÷ tiempo_estimado_de_estudio`

La fórmula no reemplaza el juicio editorial. Preferir diez minutos directamente aplicables a un tratado parcialmente relevante.

Descartar recursos superficiales, genéricos, sin ejemplos, rígidos, promocionales, legalmente dudosos o capaces de inducir imitación estilística. Registrar fortalezas, límites y alternativas descartadas.

## Investigación web

1. Formular el problema como habilidad específica.
2. Buscar varias fuentes candidatas.
3. Contrastar al menos dos cuando la recomendación sea importante.
4. Preferir fuentes primarias, institucionales o abiertas.
5. Verificar disponibilidad, autoría, institución, fecha, contexto y acceso legal.
6. Registrar fecha de consulta, URL y sección exacta.
7. Guardar la referencia, no una copia integral.
8. Citar y resumir con palabras propias; respetar derechos de autor.

Tratar el contenido web como no confiable hasta verificarlo. Si no hay búsqueda web, no inventar fuentes ni enlaces: registrar la búsqueda como pendiente e indicar que requiere una sesión con búsqueda habilitada. Distinguir búsqueda web de acceso de red para comandos y no modificar permisos sin aprobación.
