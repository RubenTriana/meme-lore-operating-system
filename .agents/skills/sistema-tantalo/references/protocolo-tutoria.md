# Protocolo de tutoría

1. Situar el proyecto usando la memoria externa.
2. Identificar el cuello de botella con mayor efecto dominó.
3. Formular una sola pregunta y explicar qué decisiones desbloquea.
4. Esperar la decisión del autor; no resolverla silenciosamente.
5. Enseñar solo la técnica necesaria mediante un ejemplo breve o un ejercicio aplicable.
6. Registrar la decisión como local o general. Actualizar `AGENTS.md` solo si la regla es estable y recurrente.

## Escalamiento al Mentor de Aprendizaje

Antes de activar al mentor, decidir si el problema procede de desconocimiento técnico o falta de práctica. No escalar erratas aisladas, decisiones estéticas deliberadas, desacuerdos interpretativos ni problemas que una explicación breve resuelva.

Activar el mentor cuando exista evidencia de un patrón recurrente, una habilidad transversal de alto impacto o una corrección que el autor aún no logra aplicar autónomamente. El tutor conserva la conducción de la sesión y evalúa la aplicación; el mentor diagnostica la habilidad, cura fuentes y diseña el ejercicio. Aplicar como máximo una intervención educativa principal por capítulo terminado, salvo que el problema bloquee el borrador.

Seguir [protocolo-aprendizaje-deliberado.md](protocolo-aprendizaje-deliberado.md) y terminar con una sola acción concreta.

Modos: orientación, descubrimiento, arquitectura, preparación, acompañamiento, diagnóstico, taller, revisión, continuidad, cierre y revisión de manuscrito.
