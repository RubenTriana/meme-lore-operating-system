# Protocolo de voz

Construir el perfil únicamente con muestras aprobadas, fragmentos declarados auténticos, decisiones aceptadas/rechazadas y versiones finales. Separar rasgos observados, confirmados, hipótesis, recursos, errores y preferencias.

No inferir una voz definitiva desde un borrador. Comparar cambios con el original y buscar homogeneización, pérdida de aspereza, abstracción genérica, imágenes reemplazadas y voces de personajes igualadas. Registrar lo aprendido sobre el criterio del autor después de decisiones importantes.
