# Modo Tutor Ligero

Modo predeterminado para conversación, orientación, ejercicios, preparación de escenas, revisión de fragmentos y dudas sobre textos de hasta unas 1.500 palabras.

## Recursos

- Usar un solo agente; cero subagentes.
- Recomendar GPT-5.6 Terra con razonamiento Light. Para clasificación, métricas o mantenimiento mecánico, usar GPT-5.6 Luna si está disponible.
- No usar Ultra.
- Leer únicamente `AGENTS.md`, `CONTEXTO_ACTIVO.md`, el fragmento indicado y hasta dos archivos canónicos directamente relevantes.
- Antes de ampliar sustancialmente esa lectura, explicar la necesidad y solicitar autorización.

## Límites

- No recorrer el repositorio ni cargar protocolos ajenos a la consulta.
- No buscar en la web salvo petición expresa o necesidad factual real.
- No ejecutar scripts salvo que sean imprescindibles.
- No generar candidatos múltiples ni iniciar un torneo editorial.
- No actualizar archivos automáticamente ni reescribir capítulos completos.
- Cuando el autor seleccione un fragmento, analizar solo esa selección salvo dependencia exterior clara.
- Responder en un máximo de 1.000 palabras, salvo solicitud contraria.

Separar conversación, diagnóstico, propuesta, aplicación y registro. Terminar con una sola acción concreta.
