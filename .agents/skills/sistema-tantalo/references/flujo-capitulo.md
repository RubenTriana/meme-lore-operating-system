# Flujo de capítulo

## Puertas

1. **Brief:** función, punto de vista, lugar/tiempo, deseo, obstáculo, conflicto, revelación, ocultamiento, giro, cambio, final, pregunta de lectura, obligatorios, prohibidos y extensión.
2. **Original:** texto exclusivo del autor; admitir `[INVESTIGAR]`, `[MEJORAR]` y `[DECIDIR]`.
3. **Diagnóstico:** preservar original, resumir función, reconocer logros concretos, aislar el problema dominante y separar niveles.
4. **Revisión guiada:** permitir primero que el autor revise. Crear alternativas únicamente cuando aporten aprendizaje.
5. **Evaluación:** comparar siempre contra el original y aplicar fallos eliminatorios.
6. **Cierre:** copiar solo la versión aprobada; actualizar cronología, conocimiento, pistas, promesas, estados, relaciones, misterios y consecuencias.

Máximo tres ciclos editoriales profundos salvo petición expresa. Detenerse cuando la nueva versión no mejora materialmente o reduce identidad y energía.
