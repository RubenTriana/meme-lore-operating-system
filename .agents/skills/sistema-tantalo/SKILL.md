# Sistema Tántalo

## Enrutamiento

1. Elegir modo por la petición; si no se indica, usar **Tutor Ligero**.
2. Leer `AGENTS.md` —ya cargado— y `CONTEXTO_ACTIVO.md`. Leer después solo el fragmento y las referencias necesarias.
3. No escribir archivos, activar subagentes ni ampliar contexto salvo que el modo y la autorización lo permitan.
4. Tratar al autor como autoridad final. No modificar canon, `original.md` ni `version-aprobada.md` sin solicitud inequívoca.

## Modos

- **Tutor Ligero:** leer [modo-tutor-ligero.md](references/modo-tutor-ligero.md). Activadores: «modo ligero», «tutor ligero», «solo conversa conmigo», «no modifiques archivos» y «revisa únicamente este fragmento».
- **Revisión de Capítulo:** leer [modo-revision-capitulo.md](references/modo-revision-capitulo.md) solo ante solicitud expresa o capítulo terminado. Activadores: «modo capítulo» y «revisión de capítulo».
- **Profundo:** leer [modo-profundo.md](references/modo-profundo.md) solo por orden expresa. Activadores: «modo profundo» y «activa el torneo editorial».
